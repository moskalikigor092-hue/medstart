# MedStart

Презентационный сайт проекта **MedStart** — онлайн-школы подготовки к поступлению в медицинский вуз
(курс «Проектная деятельность в здравоохранении»).

**Команда:** Ризаева Ясмин Имрановна, Пилипчук Каролина Евгеньевна, Прошина Дарья Викторовна, Улякина Карина Дмитриевна.

## Структура
- **index.html** — главная: обоснование, цель (SMART), целевая группа, рабочий план, результаты, SWOT, риски, команда, обратная связь
- **materials.html** — каталог материалов: подготовка к поступлению и первый курс
- **style.css**, **main.js** — оформление и интерактив
- **images.txt** — список фотографий с Unsplash; при публикации GitHub Actions скачивает их в папку img/

## Как поменять почту для формы обратной связи
Откройте main.js и впишите адрес в строку const FEEDBACK_EMAIL = '';
